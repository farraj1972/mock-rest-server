# Contributing

## Development Process

Foundation

↓

One Class

↓

Compile

↓

Functional Test

↓

Commit

## Rules

-   One Foundation at a time.
-   One class at a time.
-   Production-ready code only.
-   No pseudo-code.
-   No scope creep.
-   Keep completed foundations immutable.

## Definition of Done

-   Code completed
-   Compilation successful
-   Functional tests successful
-   Documentation updated
-   Commit created
